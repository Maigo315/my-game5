【v0.4の変更】
・草原Normal：新規通常6種・ボス1種。D候補のEasy出身は重み0.5、Normal新規1、シルバースライム0.2。通常・追加・救済の全枠共通。
・草原Normalのボス：メイドミノタウロス。S=1250 EP。S比率100/110/120/130/140/150/160/180/200%で討伐率1/5/15/30/45/60/70/85/100%。線形補間、100%未満は抽選なし。討伐報酬300/25/3（石/資材/飛躍）、大成功・通常報酬補正対象外。
・ボス勧誘：討伐時3%＋過去討伐10回ごと1ポイント＋ウサギ娘固有②1体につき2ポイント、上限100%。固定回数天井なし。全隊でボス別の討伐数を共有。未受取の加入予約も重複防止の対象。通常勧誘救済とは独立。討伐・加入の表示は報酬受取後。初討伐日時を保存するが初回報酬は未実装。
・ノーブルローズ先頭：通常の資材・飛躍報酬を無効化、固有追加・ボス報酬は対象外。今後の通常アイテム抽選にも制限フラグを利用する。甘い蜜20%（個体別抽選）、おいしいミルクはSで10%（難易度問わず）。大成功の個数倍率なし。
・甘い蜜は受取時上限5、超過破棄を表示。使用で元気+20、満タン時不可。ミルクは所持上限なし、個体10個まで、最大・現在元気+5、確認あり。探索中は両方使用不可。将来のキャンディ返却用に使用回数を保存。
・旧セーブ移行：所持・部隊・拠点・未受取・救済を保持。更新前から進行中の探索は旧勧誘候補・旧ボス無しのルールで完了し、次回から新仕様。新アイテム・ボス討伐記録は0から開始。
・未実装：草原Hard、初回討伐報酬、一般アイテム抽選・使用、カスタムアビリティ、まっさらキャンディ。従来画像がないEasyキャラは既存の代替表示を維持。

魔物娘放置探索ゲーム 試作版 v0.3.1
====================================

■ 更新方法（v0.2.1 → v0.3）
更新前に「設定 → バックアップ書き出し」を実行してください。
ZIPを展開し、同じGitHubリポジトリのルートに以下4ファイルを上書きします。
  index.html / style.css / game.js / abilities-engine.js
README.txtは任意で更新。characters.js、characters.json、costs.js、assetsは変更なし。
GitHub Pages反映後、同じURLを開き直し、v0.3と表示されることを確認してください。
セーブキーは以前と同じ、データバージョンは3。旧部隊、進行中の探索、未受取報酬、
資源、プレイヤーEXP、魔物娘、解放済みステージを引き継ぎます。
旧版からの移行時には司令室Lv.1から拠点を開始します。石の再10倍化は行いません
（v0.1から直接移行するときのみ旧単位を変換）。

■ v0.3 新機能
・拠点6施設：司令室、支給ボックス、前線基地、酒場、石碑、種族別訓練所。
・施設強化は即時。司令室Lv.2/3/4/5/6で順次解放、必要プレイヤーLv.2/7/10/14/18。
・前線基地Lv.2は資材160、Lv.3は司令室Lv.6＋資材1,000。解放した部隊は空き編成。
・支給ボックスは解放後から時間比例で蓄積。強化の石10→100個/時、資材1→10個/時。
  手動受取は整数部分のみ、小数は持越し。強化前までの生産分を保持。
・酒場は回復間隔15→10分。強化時は回復途中の割合を保持。
・石碑は大成功率+0→10ポイント。訓練所は該当種族の実効EP+0→10%。
  いずれも次の探索から反映。進行中の探索結果は開始時の条件を保持。
・施設効果は線形補間。費用は合意した暫定表、酒場・石碑は共通。
・探索・編成画面の部隊切替、ホーム画面で各部隊の進行状況を確認。
・各部隊の探索先、終了時刻、停止予約、自動周回、報酬を独立管理。
  待機中の個体は別部隊へ自動移動、探索中は移動不可。
・探索報酬の部隊別受取・全部隊一括受取。支給品は別受取。内容は受取前に非公開。
・全部隊の探索完了を時間順に処理。同時刻は部隊番号順（実装仮案）。
  オフライン経過と2時間スキップで、元気・施設生産・自動周回を共通処理。

■ v0.2.1 主な変更
・「育成」を「魔物娘」に変更し、一覧は3列、画像・名前・Lv・基本EPだけを表示。
・独立した詳細画面：大きな全身画像、基本EP、元気ゲージ、能力値、育成と固有能力。
　レベルアップで詳細を閉じず、一覧へ戻ると元のスクロール位置を復元します。
・探索画面の「固有アビリティと計算内訳」に各能力の効果量・条件・対象、
　基本EPから実効EPまでの内訳、確率・時間・石報酬補正を表示します。
　アルラウネのランダム対象が存在するときは計算例であることを表示します。
　探索中の試算と進行中の確定値を区別します。
・終了時の回復効果、実回復前後の元気、不発理由、犬娘の追加報酬などを記録。
　報酬受取後の結果画面の「探索ごとの結果・アビリティ発動履歴」から確認できます。
　設定のログにも受取後に記録されます。旧版で完了済みの探索は遡及記録しません。
・EP・元気・時間・勧誘・報酬の計算ロジックと費用データはv0.2のままです。

■ v0.2 主な変更
・Easy4地域で登場する24種類・各固有アビリティ2枠の計48枠の処理を実装。
　各アビリティが条件成立かどうかは「探索 → 固有アビリティの判定を見る」で確認。
　探索終了時の回復などは「設定 → アビリティ発動ログ」で確認。
・シルフィの固有①を、先頭キャラの攻撃・魔法+20%、防御-20%の実処理に変更。
　追加元気が足りなければアビリティのみ不発。モス娘がいれば追加消費が半減。
・割合元気消費補正→固定値軽減、探索終了時回復の同時判定、ロイド固有①②の
　個体別独立12時間制限、時間短縮の加算と上限75%を反映。
・強化の石の基本報酬・チュートリアル固定報酬・育成費用を10倍スケールへ。
・Lv.1→100の99段階の個別育成費用テーブルを採用（暫定案）。
・飛躍の石でLv.20→40→60→80→100の上限解放を追加。
・キャラクターの育成一覧から詳細モーダルを表示し、アビリティ確認とLvアップを統合。
・受取結果の各資源を改行して表示。犬娘の追加アイテム「ご褒美チケット」の個数を保存。
・v0.1のセーブデータを初回起動時に自動変換（保有・未受取の強化の石を10倍）。

■ 試作用の仮ルール・未実装
・同率最多ステータスの判定は同率も成立と扱います。
　デーモンの『最も高いステータス一つ』は攻撃→防御→魔法の順で1つ選びます。
・補正は基本値+固定値の後に割合を合算し、地形補正・適性・EP倍率を適用。
　EPの表示は整数切り捨て、端数の資源報酬は確率的に1個を追加。
・通常探索の元気消費量は割合補正の後で固定値補正、端数は切り上げ。
　追加消費はシルフィの固有①のみ。アルラウネの対象は毎回独立抽選です。
・元気条件、大成功率などは探索開始時に判定、回復対象は終了直後の元気で一括判定。
・犬娘の「強化の石1個」の追加ドロップは旧単位比を保つため10個としています（仮）。
・大成功率・勧誘率は0〜100%に制限。通常勧誘失敗の救済はv0.3.1で実装。
・ウサギ娘のボス勧誘+2ポイントの内部計算は用意しましたが、ボス戦が未実装なので
　まだゲーム中では発動しません。草原Normalの新顔6種類とメイドミノタウロスも未実装。
・開発用の時間スキップは2時間単位。セーブはスマホの同じブラウザに保持。
・カスタムアビリティ、アイテム使用は未実装。
・v0.1から引き継いだ進行中の探索は、その1回だけ旧スナップショットを保持して精算します。
　また、既に費やした石は払い戻しません。比較テストではバックアップを保存したうえで
　初期化して新規プレイすることを推奨します。
・試作版はローカル保存のみ。ブラウザデータ消去に備えてバックアップしてください。
