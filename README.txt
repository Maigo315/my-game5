■ 新機能
・カスタム29系統。初期1枠、最大3枠。開花の証で空き枠解放。初期習得率は通常50%、ボス100%。同一個体の同系統重複不可。地域違いは別系統。地域限定の対象は解放済み地域から均等抽選。
・レアリティ先行抽選 C40/UC30/R20/SR7/UR3。その等級の有効系統を均等抽選、等級内数値と地域を均等抽選。時間延長はC/UCのみ。特殊6種はR/SR/URのみ。メダルは単発・新旧選択、約1秒の発光演出（タップで省略可）、抽選結果未選択でも保存されます。
・幸運合計1につき通常基本勧誘+0.2pt、追加+0.1pt、ボス+0.01pt。D未満通常勧誘なし。最終確率上限100%。果実の使用上限なし。
・アイテム一覧「道具」。個体への使用は個体詳細。探索中は個体アイテム・カスタム変更不可。ご褒美チケット50回復。聖獣の懐中時計は進行中の全部隊を即時完了、自動周回を全解除、時計自体では時間を進めない。まっさらキャンディはLv1/上限20/空き1枠、石・飛躍・証・果実・ミルクを返却、メダルなし、現在元気は新上限まで保持（回復なし）。クールダウンはリセットによる悪用防止のため維持。
・探索アイテム13種は出発画面で1個選択。出発成功時だけ消費、自動周回は初回のみ。探索応援20%、時間±30%、各確率補正等は合意仕様。時間短縮75%/延長50%まで。要求EP軽減は通常到達度のみ、討伐支援は通常Sかつ元のS要求EP以上でのみ有効。討伐支援は討伐曲線の基準EPを0.8倍。報酬ブーストは通常基本報酬に1.3倍、ボス報酬は独立。大成功倍率は1.5にカスタム分を加算。回復効果は終了時に合算後上限適用。
・運命の出会いは過去の加入済み種類、未受取加入分を除外。未受取探索報酬がある間は内容を推測できないようセット出発不可。対象がいなければ出発不可。別部隊が出発後に最後の未加入候補を獲得した場合は通常の基本勧誘に切替え、消費したセットは受取報酬で返却（暫定裁定）。
・通常ドロップD/C/B/A/S=10/20/30/40/50%、大成功は追加1枠確定、ボス討伐は独立50%で大成功用テーブル。D未満通常・大成功ドロップなし。ノーブルローズ先頭は通常・大成功ドロップなし、固有能力とボス報酬は例外。難易度別テーブル・区分内重みはv05.js内。Normal初回討伐メダル5個。
・交易所は司令室Lv3から（レベルなし）。換金レート 強化石1/拠点資材10/飛躍石20。販売品は価格50%で換金、非販売品は指定個別額。販売価格・初期在庫・上限はv05.js内。解放時刻から24時間/168時間ごとに補充（暦日の0時ではない）。オフライン、時間スキップも対応。探索商品は12種類中異なる4種類を1個ずつ補充、満杯なら追加なし。開花の証初期在庫0。Hard以降未実装のため攻略実績による入荷イベントは今後追加。
・エルフの同率最大判定は従来どおり両方成立、計算内訳に同率最大を明示。

■ 暫定裁定・未実装
カスタムの同種ステータス/個別EP補正は加算、探索応援は部隊合計への乗算。追加消費軽減は消費者本人（シルフィなら先頭）、モス半減と乗算・追加消費ごとに切り上げ。自然回復速度は待機時の回復間隔を倍率で割る。既存施設強化費用、レベル費用、飛躍の石供給量、ボス曲線は変更していません。
初心者ミッション、プレイヤーレベル節目報酬、他地域Normal/Hard以降、終盤専用商品（円柱・球体・角柱・羽）は未実装。
