魔物娘放置探索 試作版 v0.1
==========================

【起動方法】
ZIPを展開し、index.html をブラウザで開きます。
GitHub Pagesでも動作します。リポジトリのルートに中身をアップロードし、
Settings > Pages > Deploy from a branch から main / (root) を選択してください。
公開されたURLをスマホで開けます。

【実装済み】
・スマホ縦画面を意識した基本画面、添付済みキャラ画像19種
・初期3人（スライム娘／ゴブリン娘／マイコニド）
・チュートリアル（即時完了、元気無消費、犬娘＋固定報酬）
・草原Easyを含むEasy4ステージのEP・報酬と条件付き開放
・通常勧誘・到達度・大成功の基本処理
・未受取報酬の蓄積、手動開封、経験値・キャラ追加
・編成、Lv20までの強化、1部隊自動周回、自然回復
・2時間単位の開発時間スキップ、オフライン経過計算
・ローカル自動保存、バックアップ書き出し／読み込み

【未実装・仮処理】
・全48枠アビリティのうち一部のみ実処理しています。
  とくにシルフィのEP補正は仮値、回復・追加元気消費の処理も完全ではありません。
・キャラクターの初期ステータスと成長タイプは資料から転記しています。
・育成コストは仕様書の節点から線形補間した仮値です。
・施設、飛躍の石による上限解放、複数部隊、ボス、
  草原Normalの新顔6種、勧誘連続失敗保証などは今後実装します。
・大成功率・勧誘率の一部条件、EP算出順も検証用の仮ルールです。
・犬娘の「ご褒美チケット」は抽選表示しますが所持管理は未実装です。
・公開GitHub Pagesは一般公開される場合があるため、個人情報や秘密のデータを置かないでください。
・ブラウザの保存データは端末ごとです。定期的にバックアップしてください。

この試作品は操作感の確認用です。数値バランスを評価する前に、
アビリティ・施設・勧誘救済などを順次実装する必要があります。
