・フォレストリッチ：基本消費とシルフィ追加消費を確保後に自身の追加20を支払い、成功すれば大成功倍率+30pt（不足時は能力のみ不発）。先頭時、終了時回復前の自身の元気50以下で、軽減後の追加消費を支払える他者1人を均等抽選。相手の元気を消費し自身を20回復。開始・終了ともモス娘半減と消費者本人のカスタム軽減を乗算、切上げ。回復量はメイジの補正対象、消費と回復は独立。回復前スナップショットで条件を判定し、消費・回復合算後に元気上下限を適用。
・エビルアルラウネ：大成功率−5pt、通常要求EP−5%を加算。先頭時、全員の防御−5%、自身の攻撃+20%。ボス本来のS条件は変えない。

■ v0.7.7 魔物娘研究（v0.7.6.2ベース）
・最初から利用可能。研究値は種類IDごとに累積。既存の加入履歴・所持個体・資源・セーブキー（majo-explore-v01、内部version=5）を維持。旧セーブは研究値0、再勧誘救済0、同種を残す設定1体から開始。
・characters.js / characters.json の researchValue：スライム娘1、他通常2、シルバースライム8、ミミック娘6、現行Normalボス5（将来個別調整可）。
・5/15/30で実効EP各+1%、50で大成功率+3ポイント、100でEP+2%、200で研究枠+1。以降 round(200×1.5^n)（n=1,2,...）でEP+1%ずつ。上限なし（安全な整数の範囲で管理）。個別EP補正に加算、大成功率は各個体分を加算しシルキー判定前に反映。固有②複製対象外。
・研究枠は通常3枠と別データ researchCustom（内部スロット番号3）。開花の証は通常枠のみ、メダル抽選・同系統除外・レアリティフィルタ・探索能力は研究枠も対象。キャンディは研究枠の能力を消去するが解放と研究値は保持、証の返却は通常枠の実使用分のみ。
・個別お別れは個体詳細末尾。一括選択は魔物娘一覧、検索・絞込に対応、選択保持、固定操作欄。自動選択では同種1〜4体残す（初期1、設定保存）、対象外・非表示・残した個体も残数に含める。残す優先は実Lv、最高カスタムレア、習得数、入手の古さ。手動選択は最後の1体まで。お気に入り・保護・編成/探索・看板娘（実表示個体含む）・プリセット・共鳴中・最後の1体・ボスは不可。最終確認で再検証し、一件でも不適合なら全件中止。URは除外せず注意表示。育成済みも可、返却なし。共鳴基準の低下・自動解除は事前表示し、解除CTなし。
・ボス初回勧誘は従来通り。加入済みまたは未受取加入予約済みのボスは再勧誘。討伐後の再勧誘失敗10回ごと+1ポイント、成功で専用カウント0。全隊共有、累計討伐は維持。討伐失敗はカウントなし。再勧誘は完了時確定、研究値は報酬受取時に加算。成功ごとに「〇〇の研究が進んだ！」「研究値+5」。再勧誘成功はカーミラの勧誘成功条件に含めるが、加入個体・通常勧誘救済には含めない。旧版出発済み探索は旧ルール、更新後の出発から再勧誘適用。既存の未受取報酬に遡及加算なし。
・図鑑に研究タブと研究値順ソート。生態未執筆は非表示、出現情報→出現、アビリティタブ幅を広く。個体詳細から研究タブへ移動し復帰。用語集追加。ホーム、共鳴、育成費用、基本報酬は変更なし。
